# 코딩 놀이터

GitHub Pages `/sayeon/coding/`에서 바로 실행하는 독립적인 블록 학습 과정이다.
Code.org의 목록 → 단계 선택 → 블록 조립 → 실행 → 성공 흐름을 참고했으며,
캐릭터·문제·학습 자료는 새로 작성했다. Code.org 계정이나 서버를 사용하지 않는다.

- 10개 수업 × 10단계: 미로 60, 그림 30, 방향 이벤트 10.
- `curriculum.mjs`: 수업·목표·사용 블록·블록 제한·힌트.
- `engine.mjs`: 제한된 명령을 직접 해석하고 이동·충돌·그림을 판정한다. eval을 쓰지 않는다.
- `app.mjs`: Blockly, 화면, 단계 이동, 진도·작업 공간 저장.
- `vendor/`: Blockly 12.5.1 (Apache-2.0) 및 한국어 메시지. 외부 CDN 없이 실행한다.
- 브라우저 저장 키는 `codingPlayground_v1`. 완료 여부와 단계별 블록을 저장하며,
  기기 간 동기화나 교사용 학생 관리 기능은 없다.
- `#lesson=1`부터 `#lesson=100`까지 특정 단계로 직접 이동한다.

수업을 변경했으면 `node --test tests/coding.test.mjs`로 목표·제한·무한 반복 방어를 확인한다.
화면 파일/블록 정의가 바뀌었으면 브라우저에서 이동 블록 연결, 실행, 저장 복원,
그림·이벤트 실행과 좁은 화면도 확인한다. 기존 사연·말씀·음성 자료와는 독립적이다.
