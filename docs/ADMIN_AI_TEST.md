# 관리자 AI 질문 테스트 — 2026-10-04

## 사용자 결정과 공개 범위
- 관리자 로그인 후 admin에서만 테스트한다. 일반 앱에는 연결하지 않는다.
- 사용자가 "되었다", "앱에 넣어 달라" 등으로 명확히 승인한 뒤 일반 앱 통합을 별도 작업으로 진행한다.
- admin/index.html, admin/ai-lab.html, admin/ai-lab.mjs, admin/ai-core.mjs만 기능 관련 파일이다.
- 일반 index.html, stones/index.html, malsseum/index.html, manifest.json, 설정·음성·원고에는 AI 링크를 넣지 않는다.

## 접근 제한
- 기존 Supabase get_analytics_dashboard RPC의 서버측 analytics_admin_emails 확인을 재사용한다.
- 관리자 통계 조회 성공 후에만 테스트 링크가 보인다. 토큰만 있다고 화면을 먼저 열지 않는다.
- 테스트 URL을 직접 열어도 로그인 없거나 서버 관리자 권한 검증에 실패하면 입력 화면을 숨긴다.
- 자료 불러오기, TXT 추가, 검색, AI 요청 때마다 서버 권한을 다시 확인한다.
- Pages의 HTML/JS 소스 자체는 공개 파일이다. 링크를 숨기는 것 자체를 보안으로 간주하지 않는다.
- 공유 API 키나 원고 평문을 공개 파일에 포함하지 않는다. 테스트는 각 관리자가 자기 무료 키를 입력해서 직접 호출한다. 공용 AI 서버는 아직 배포하지 않았다.

## 테스트 방법
1. /sayeon/admin/에서 허가된 Google 계정으로 로그인한다.
2. AI 질문 테스트 열기를 누른다.
3. 등록된 말씀·사연 불러오기. 기존 원고 암호가 저장되지 않았다면 원고 열기 암호를 입력한다.
4. 키 없이 원문 검색부터 확인한다. 범위와 출처를 확인한다.
5. Gemini 또는 Groq를 선택하고 결제를 연결하지 않은 무료 프로젝트/계정 키를 입력한다. 키를 채팅이나 저장소에 붙여넣지 않는다.
6. 무료 등급 확인 체크 후 질문한다. 업체에는 질문과 최대 6개, 총 8,000글자 이하 근거 원문만 전송한다.
7. 인내·감사 질문, 자료에 없는 날씨 질문, 같은 질문 재사용, 범위 변경, 로그아웃 후 직접 URL 접근을 검사한다.
8. 새 원고 반영은 테스트 화면 새로고침 후 다시 불러오기. 테스트 자료와 답변 캐시는 현재 화면 메모리에만 있다.

## 지원 모델과 무료 조건
- Gemini 2.5 Flash-Lite / Gemini 2.5 Flash: Google 공식 가격표의 무료 등급 지원 모델.
- Groq openai/gpt-oss-20b: Groq 무료 등급 모델. OpenAI ChatGPT 유료 계정·API를 사용하는 것이 아니다.
- 업체별 키·접근 권한·일일/분당 토큰 한도는 계정에 따라 달라진다.
- 화면에서 키가 무료인지 자동 판별할 수 없다. 유료 결제 없는 프로젝트/계정의 키만 사용한다.
- 키는 password 입력에만 두고 저장소, localStorage, sessionStorage, URL, 로그에 저장하지 않는다. 새로고침·페이지 떠나기·로그아웃·지우기 때 삭제한다.
- 화면당 AI 호출 시도 최대 30회. 업체의 실제 남은 한도를 나타내는 숫자는 아니다.
- 다른 업체 자동 전환은 없다. 사용자가 모델을 직접 선택해야 자료가 해당 업체로 전달된다.
- 429/401/403/404, 네트워크/CORS 오류는 표시하고 원문을 유지한다. 유료 전환·무한 재시도하지 않는다.
- 무료 API 키가 제공되지 않아 실제 업체 호출 성공은 제작 단계에서 검증하지 않았다. 요청 형식과 오류 처리는 모의 응답으로 검사했다.

## 근거와 검증
- 기존 암호화 JSON을 SaCrypt로 현재 브라우저에서 연다. 복제·수정·평문 게시하지 않는다.
- 2026/2025 성령사연, 월명동 sections, 말씀 paragraphs의 일반 배열·p·h를 지원하고 hr을 건너뛴다.
- 한국어 단어, 일부 조사 정리, 두 글자 중복 및 소규모 동의어 기반 검색이다. 의미 임베딩 검색은 아직 아니다.
- 말씀 원문 링크는 /sayeon/malsseum/을 유지한다. 자료는 /malsseum/malsseum.json.enc에서 읽는다.
- 근거 부족이면 AI를 호출하지 않는다. JSON 답변의 모든 설명 문장에 실제 문단 ID와 최소 8글자 연속 인용을 요구한다.
- 인용 문자열이 원문에 실제 있는지 검증한다. 사실 의미까지 자동 증명하는 검사는 아니다. 관리자 원문 검토가 필요하다.
- source와 inference 표시를 구분한다. 인터넷 도구·URL 문맥·웹 검색을 API 요청에 넣지 않는다.
- 자료 안 명령은 데이터로 취급하도록 지시한다. 시스템 지시만으로 환각·프롬프트 주입을 완전 방지한다고 주장하지 않는다.
- API 응답·원고는 textContent로 렌더링한다. AI 생성 HTML/링크는 실행하지 않는다.
- TXT 업로드는 최대 1MB, 화면 메모리만 사용하며 자동 서버 저장·공유하지 않는다.

## 앱 통합 승인 후 필요한 일
- 사용자 승인 기록 후에만 일반 앱 버튼을 추가한다.
- 공용 키를 사용하려면 서버 Secrets에 보관하고 로그인 권한, 무료 한도·토큰·요청 속도 제한을 서버에서 집행한다.
- 유료 결제 없는 프로젝트/계정 유지, 데이터 처리 조건, 회원별 접근 자료를 확인한다.
- 검색 누락·자료 밖 답변·한국어 품질·동시 100명·무료 토큰 한도를 실제 테스트한다.
- 일반 앱과 관리자 테스트의 공개 스위치를 분리한다.
