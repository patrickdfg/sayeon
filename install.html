안드로이드 (삼성·크롬)

  1. 위 QR을 찍거나 성령 사연 열기를 누릅니다.
  2. 화면 아래·위에 앱 설치 또는 홈 화면에 추가 안내가 뜨면 누릅니다.
  3. 안 뜨면 오른쪽 위 ⋮ → 홈 화면에 추가를 누릅니다.

아이폰 (사파리)

  3. 목록을 내려 홈 화면에 추가를 누르고 추가를 누릅니다.
