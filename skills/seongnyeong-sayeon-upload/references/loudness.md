# D. 소리 크기 규칙

- 새로 올리는 소리는 종류(육성·현수·Melo·말씀)와 확장자를 가리지 않고 **-16 LUFS**(ebur128 통합 음량). 꼭대기는 -1 dBFS 이하(현수·말씀 mp3 는 -2 목표).
- 이미 게시한 소리는 요청 없이 일괄 변경하지 않는다. 월명동 가이드 녹음(`stones/audio/*-guide.mp3`)은 규칙에서 뺀다.
- 그냥 키우면 꼭대기가 찢어진다. `tools/loud16.py`(키우기 → 리미터 → 잰 값 확인 반복)로 만든다.
  - `python tools/loud16.py 원본 결과 [기존파일]`, `--fix 파일…`(제자리), `--fix-new`(새로 생긴 `audio/*.mp3`)
- 길이가 0.3초 넘게 바뀌면 문단 시간표가 어긋난다. 도구가 되돌린다.
- 자동으로 되는 것 — 글 등록의 현수 mp3(`--fix-new`), `[원본]` 육성, 말씀 탭 mp3. 직접 올리는 육성·현수 TTS(말씀)는 직접 맞춘다.
- 잴 때는 `scripts/check_audio.py <파일>` (ffmpeg 필요).
- 이 -16 은 사용자가 시험 뒤 정한 기준이지만, 기존 파일은 -18.4 인 것이 많다. 비교는 새 파일끼리만 한다.
